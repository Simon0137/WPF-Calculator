## Описание проекта

PF Calculator — приложение на C#, предназначенное для расчёта предполагаемого
пенсионного капитала на основе текущего возраста пользователя, целевого возраста
выхода на пенсию, имеющихся сбережений, размера ежемесячного взноса и ожидаемой
годовой доходности инвестиций.

Программа позволяет определить:

- количество лет до выхода на пенсию;
- общую сумму внесённых средств;
- доход от инвестиций;
- итоговый капитал к моменту выхода на пенсию.

## Требования

Для запуска программы требуется:

- операционная система Windows;
- установленная среда выполнения, соответствующая версии .NET, используемой
  при разработке проекта;
- исходные файлы проекта PF Calculator.

## Запуск программы

1. Открыть проект в Visual Studio.
2. Открыть файл решения проекта (`.sln`) или файл проекта (`.csproj`).
3. Собрать проект с помощью команды Build → Build Solution.
4. Запустить приложение с помощью кнопки Start или клавиши F5.

После запуска открывается окно PF Calculator с полями для ввода исходных данных.

## Использование программы

Пользователю необходимо последовательно указать:

1. Текущий возраст — возраст пользователя на данный момент.
2. Целевой возраст — возраст, в котором пользователь планирует выйти на пенсию.
3. Текущие сбережения — сумма уже имеющихся накоплений в евро.
4. Ежемесячный взнос — сумма, которую пользователь планирует вносить
   каждый месяц.
5. Ожидаемый % год. доход-ти — предполагаемая годовая доходность инвестиций
   в процентах.

После заполнения всех полей необходимо нажать кнопку «Рассчитать».

Программа выводит:

- Лет до пенсии — количество лет между текущим и целевым возрастом;
- Вы внесете всего — сумма текущих сбережений и всех ежемесячных взносов
  за период до пенсии;
- Доход от инвестиций — часть итогового капитала, полученная за счёт
  начисления инвестиционного дохода;
- Итоговый капитал — общая сумма, которая предположительно будет накоплена
  к моменту выхода на пенсию.

## Формула расчёта

Количество лет до пенсии определяется как:

    Лет до пенсии = Целевой возраст − Текущий возраст

Количество месяцев до пенсии:

    Количество месяцев = Лет до пенсии × 12

Для расчёта будущей стоимости накоплений используется предполагаемая
ежемесячная капитализация доходности.

Месячная доходность определяется как:

    Месячная доходность = Годовая доходность / 12

Итоговый капитал рассчитывается с учётом:

- текущих сбережений;
- регулярных ежемесячных взносов;
- инвестиционного дохода.

Общая сумма внесённых пользователем средств:

    Всего внесено = Текущие сбережения +
                    Ежемесячный взнос × Количество месяцев

Доход от инвестиций:

    Доход от инвестиций = Итоговый капитал − Всего внесено

## Контрольный пример 1 — корректные входные данные

### Входные данные

| Параметр | Значение |
|---|---:|
| Текущий возраст | 25 |
| Целевой возраст | 65 |
| Текущие сбережения | 5000 € |
| Ежемесячный взнос | 200 € |
| Ожидаемая годовая доходность | 6 % |

### Ожидаемый результат

    Лет до пенсии: 40
    Вы внесете всего: 101000 €
    Доход от инвестиций: 352085.42 €
    Итоговый капитал: 453085.42 €

## Контрольный пример 2 — некорректные входные данные

### Входные данные

Например:

    Текущий возраст: 65
    Целевой возраст: 50
    Текущие сбережения: 5000 €
    Ежемесячный взнос: 200 €
    Ожидаемая годовая доходность: 6 %

Расчёт не выполняется, поскольку целевой возраст выхода на пенсию
